# 智能交通系统方案设计智能体 — 标准知识库入库索引 INDEX.md
## 文档用途
1. 统一管控知识库内所有国标、行业标准，防止智能体编造不存在的条款、虚假标准号；
2. 智能体生成方案时，只能调用本清单内已入库的标准，自动校验引用合法性；
3. 标准按业务模块分类，匹配方案设计的子系统内容。

## 一、引用校验强制规则（智能体内置约束）
1. 所有条文引用必须严格匹配【标准号+条款号】，不允许自创标准号、编造未收录标准；
2. 仅允许引用本清单中标注【现行】的文件；【废止/征求意见稿】不得写入正式设计方案；
3. 引用格式统一：GB/T 39898-2021《智能交通管理系统建设技术规范》第X.X条；
4. 若方案涉及预算、施工、设备选型，必须同时匹配对应工程类国标与交通设备行业标准；
5. 未入库的标准一律不得出现在输出文本中，智能体遇到未知标准自动提示“暂无对应标准，请补充入库”。

## 三、知识库维护规则
1. 新增标准：必须先把标准号、名称、状态录入本表，再上传PDF原文到对应文件夹；未录入INDEX.md的文件，智能体禁止读取；
2. 标准更新：一旦标准废止，立即在本表标记【废止】，智能体自动屏蔽该文件；
3. 方案引用溯源：智能体每输出一条规范条文，自动附带本条索引内对应的标准编号，方便核验真伪。
